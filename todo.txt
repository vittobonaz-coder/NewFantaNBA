- Aggiornamento dati giornaliero
    Render non ha un "cronjob" (operazione pianificata) nel piano free. 
    Per aggiornare i dati alle 9:00 ogni giorno hai due opzioni:
    1. Aggiornamento "Lazy" (Pigro): Quando il primo utente della 
        giornata apre l'app dopo le 9:00, il codice controlla se il 
        file JSON è aggiornato a oggi. Se non lo è, scarica i dati e 
        salva il file.
    2. GitHub Actions: Puoi creare uno script che gira su GitHub 
        ogni mattina alle 8:00 UTC (9:00 ITA), scarica i dati e fa un 
        "auto-commit" dei file JSON nel tuo repository. Render vedrà il 
        nuovo commit e farà il deploy automatico con i dati freschi.
